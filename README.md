# 笔记应用 (Notes App)

一个简洁、功能丰富的纯前端笔记应用，支持增删改查、搜索、深色模式、Markdown 预览、回收站等功能。

## 功能特性

### 核心功能
- **笔记管理** - 创建、编辑、删除笔记
- **实时搜索** - 按标题或内容搜索笔记
- **自动保存** - 编辑内容自动保存到浏览器（500ms 防抖）
- **字数统计** - 实时显示字数和预计阅读时间

### 数据管理
- **回收站** - 删除的笔记可在回收站找回
- **文件导出** - 单条笔记导出为 `.md` 文件
- **批量导出** - 所有笔记导出为 `.json` 备份文件
- **文件导入** - 支持导入 `.txt`、`.md`、`.json` 文件
- **拖拽导入** - 直接拖拽文件到编辑器区域导入

### 界面与体验
- **深色模式** - 一键切换深色/浅色主题，支持持久化
- **Markdown 预览** - 支持标题、粗体、斜体、代码、列表、引用、分割线
- **笔记排序** - 按更新时间 / 创建时间 / 标题排序
- **响应式设计** - 完美适配桌面端和移动端
- **移动端侧边栏** - 汉堡菜单按钮，滑出侧边栏
- **键盘快捷键** - `Ctrl+N` 新建，`Ctrl+S` 保存，`Esc` 关闭对话框

## 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架依赖）
- localStorage 本地数据存储
- CSS 变量实现深色模式
- CSS Grid/Flexbox 响应式布局
